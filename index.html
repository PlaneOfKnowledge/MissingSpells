Load a *-MissingSpells.txt file, sort & search, and tick off spells. Your checkmarks are saved per file name.
How to dump a missing-spells file in EverQuest
  1. Log in the character you want to check and open the in-game chat window.
  2. Type /outputfile missingspells and press Enter.
  3. EverQuest writes a file named <Character>_<server>-MissingSpells.txt (e.g. Aleran_teek-ENC-MissingSpells.txt).
  4. Find it in your EverQuest install folder (default C:\Users\Public\Daybreak Game Company\Installed Games\EverQuest).
  5. Come back here, click Load File…, and pick that file.
Tip: run the command again anytime to refresh the list as you learn new spells.
